# Моделирование: Опорность

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения стоя на двух ногах, находим центр тяжести и пятно опоры – предполагаемые. Смещая центр тяжести за границей пятна опоры (движениями в стороны, вперед-назад), определяем положение, где начинается соскальзывание и непроизвольное натяжение тканевых объемов, и где находится положение распределение веса на все кости |  |  |  |
| 2 | Из положения стоя, зависнуть в положении баланс, двигаем центр тяжести (на миллиметры в идеальном варианте) за границу пятна опоры, за соскальзывание в развитие падения (страхуем себя ногой). Задача – найти скорость развития падения своего тела. Повторить 5–6 раз, уменьшая шаг движения центра тяжести |  |  |  |
| 3 | Из положения стоя, зависнуть в положении баланс, двигаем центр тяжести (на миллиметры в идеальном варианте) за границу пятна опоры, за соскальзывание в развитие падения. В начале падения развиваем усилие на стягивание ленты – возвращая себя в состояние баланса. Какое смещение вы можете себе позволить (надежно вытягиваете в баланс)? |  |  |  |
| 4 | Из положения лодочки на боку смещаем верхнюю сторону тазовой кости за границу пятна опоры. В момент прохождения границ опоры проявятся непроизвольные напряжения (для подхватывания тела – работа нервной системы). Пробуем вернуться на границу – тканевые объемы начнут вытягиваться. К этому усилию добавляем такое же, произвольное усилие, чтобы доделать лодочку и ее приподнять. |  |  |  |
