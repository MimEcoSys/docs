# Моделирование: Перекаты, часть 1

Возникающие сложности в перекатах решаем проскальзыванием. Если сложно даются перекаты – они могут быть проработаны в рамках классов системного фитнеса. О классах есть информация на сайте ШСМ.

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

| 2 | Из положения на четвереньках перекатываем ладонь со смещением плеча |  |  |  |
| 3 | Из положения на четвереньках перекатываем обе ладони одновременно, в противоход |  |  |  |
| 4 | Из положения стоя, с упором лопатками на стену, руки опущены или лежат вдоль стены – перекатываемся в сторону по стене (воротничок, область ожерелья прокатываем по стене) |  |  |  |
| 5 | Из положения сидя, с упором на руки, прокатываем по полу седалищные кости |  |  |  |
