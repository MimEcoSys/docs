# Моделирование: Плечо-лопатка, часть 3

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
|  | 1 | Из положения не симметричный замок спереди (сидя на полу, сводим согнутые руки перед собой и заводим один локоть за другой – для облечения можно поставить локти на стул) создаем преднатяжение. Развиваем усилие до давления локтя в сторону пола. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
|  | 2 | Из положения не симметричный замок спереди (сидя на полу, сводим согнутые руки перед собой и заводим один локоть за другой – для облечения можно поставить локти на стул) создаем преднатяжение. Развиваем усилие до давления локтя в сторону потолка. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
|  | 3 | Из положения не симметричный замок спереди (сидя на полу, сводим согнутые руки перед собой и заводим один локоть за другой – для облечения можно поставить локти на стул) создаем преднатяжение. Развиваем усилие до давления локтя к локтю в направлении право-лево. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
|  | 4 | Из положения не симметричный замок спереди (сидя на полу, сводим согнутые руки перед собой и заводим один локоть за другой – для облечения можно поставить локти на стул) создаем преднатяжение. Развиваем усилие до растяжения локтей друг от друга в направлении право-лево. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |

Развиваем усилие до стягивания плеча к локтю. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Развиваем усилие до вытяжения плеча от локтя. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Развиваем усилие до разведения запястий (вращение плеча). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды.
