# Моделирование: Координационная заплатка по трем контекстам

Приемы моделирования рекомендуем выполнить в три круга:

1. Определить нарушения в распределении в трех контекстах

Тестирование изменения амплитуд в каждом контексте

Проверка улучшенной заплатки (если потребовалось улучшать)

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения упор боком, сплошной и равносильной лентой, пробуем углублять прогиб. К найденному ограничению подбираем и применяем координационную заплатку |  |  |  |
| 2 | Из положения вывешивания, сплошной и равносильной лентой с тем же усилием, пробуем усилить прогиб. К найденному ограничению подбираем и применяем координационную заплатку |  |  |  |
| 3 | Из положения лодочки, сплошной и равносильной лентой с тем же усилием, пробуем усилить прогиб. К найденному ограничению подбираем и применяем координационную заплатку |  |  |  |
| 4 | Три найденные заплатки, объединяем в одно тканевое чувство – одну гифку выучиваем |  |  |  |
| 5 | Повторяем приемы 1–4 для второго бока |  |  |  |
