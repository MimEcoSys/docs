# Моделирование: Выполнение замеров

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.Все замеры зафиксируйте, если допустимо, то на стене – бумажным скотчем, наклейкой, карандашом (нужно сохранить замер, не повредив стены). Если не допустимо отметки оставлять на стене - на голову/плечо можно накинуть сантиметр или веревку, и измерять расстояние до пола.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Поворот. Становимся спиной к стене, на расстоянии в пол шага и начинаем поворачиваться к стене, влево не развивая усилия. Какой этаж в теле начал сопротивляться первым? Пробуем по памяти дорасслабить, или напрячь другие объемы для достижения равномерности. Распределяем натяжение и не наращивая усилия пробуем увеличить амплитуду, найденные ограничения фиксируем |  |  |  |
| 2 | Поворот. Становимся спиной к стене, на расстоянии в пол шага и начинаем поворачиваться к стене, вправо не развивая усилия. Какой этаж в теле начал сопротивляться первым? Пробуем по памяти дорасслабить, или напрячь другие объемы для достижения равномерности. Распределяем натяжение и не наращивая усилия пробуем увеличить амплитуду, найденные ограничения фиксируем |  |  |  |
| 3 | Прогиб в сторону. Становимся спиной к стене, на расстоянии в пол шага. Определяем пятно опоры и общий центр тяжести, тянем таз влево, при этом отклоняясь верхней частью корпуса вправо. Распределяем натяжение и не наращивая усилия пробуем увеличить амплитуду, найденные ограничения фиксируем |  |  |  |
| 4 | Прогиб в сторону. Становимся спиной к стене, на расстоянии в пол шага. Определяем пятно опоры и общий центр тяжести, тянем таз вправо, при этом отклоняясь верхней частью корпуса влево. Распределяем натяжение и не наращивая усилия пробуем увеличить амплитуду, найденные ограничения фиксируем |  |  |  |
| 5 | Прогиб назад. Становимся спиной к стене, на расстоянии в шаг. Определяем пятно опоры и общий центр тяжести, тянем таз вперед, при этом отклоняясь верхней частью корпуса назад. Распределяем натяжение и не наращивая усилия пробуем увеличить амплитуду, найденные ограничения фиксируем |  |  |  |
