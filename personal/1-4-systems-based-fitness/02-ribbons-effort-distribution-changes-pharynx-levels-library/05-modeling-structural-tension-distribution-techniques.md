# Моделирование: Распределение натяжения

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

В ходе тренировок каждый телесный процесс важно описывать с трех позиций: ощущения, регуляция, действие. Эти три калиброванные друг о друга описания повышают соответствие телесного процесса - выполняемой задаче.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Наклон. Становимся спиной к стене, на расстоянии в пол шага. Определяем пятно опоры и общий центр тяжести. Верхнюю часть скелета тащим в сторону. При этом общий центр тяжести может выйти за пятно опоры и может потребоваться дополнительное мышечное усилие, чтобы себя удержать от падения. Обращаем внимание на это необходимое усилие, для удержания тела, какие воксели включились? |  |  |  |
| 2 | Прогиб. Становимся спиной к стене, на расстоянии в пол шага. Определяем пятно опоры и общий центр тяжести и тянем таз влево, при этом отклоняясь верхней частью корпуса вправо. Общий центр тяжести остается внутри пятна опоры. Обращаем внимание, что усилия для поддержания падающего тела не требуется. |  |  |  |
| 3 | Находясь в прогибе, пробуем организовать положение костей относительно друг друга таким образом, чтобы натяжение от головы до стоп было сплошным и равносильным (например, может сильно тянуть поясницу, а другие воксели на этом фоне могут не ощущаться, можно уменьшить прогиб, чтобы снять часть натяжения поясницы, чтобы различалось ощущение натяжения в соседних вокселях) |  |  |  |
| 4 | После того как найдено комфортное положение в прогибе, пробуем прогнуться больше, сохраняя равномерность натяжения |  |  |  |
| 5 | Выполняем прогиб в другую сторону, до нахождения комфортной позы |  |  |  |
| 6 | После того как найдено комфортное положение в прогибе, пробуем прогнуться больше, сохраняя равномерность натяжения. Удалось ли увеличить амплитуду, управляя натяжением (распределяя натяжение)? |  |  |  |
| 7 | Поворот. Становимся спиной к стене, на расстоянии в пол шага и начинаем поворачиваться к стене, до первого тянущего ощущения. Распределяем усилие до сплошного и равносильного (например, тянущее ощущение в пояснице, подобрали поясницу, горло слабовато натянуто – доводим голову, поиграли позвонками, пошевелили вперед-назад шеей – находим поисковыми усилиями (где-то больше, где-то меньше) такие положения, где тянуть будет одинаково). Получается ли после распределения увеличить поворот? |  |  |  |
|  | Поворот. Повторить в другую сторону |  |  |  |
