# Моделирование: Напряжение тканевых объемов по стрелкам

Выполните перечисленные приемы и запишите результаты. В независимости от движения - если встретили боль, то отступаем по амплитуде и интенсивности усилия.

Для проверки – было ли напряжение в тех же самых тканевых объемах, что и ранее – можно возвращаться к предыдущим действиям

Иллюстрация к первому приему на моделирование:

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Обратим внимание на кость плеча, например левой руки, правую ладонь размещаем на локте левой руки и используем ее как упор, для левой руки. Пробуем приложить усилие поперек кости наверх |  |  |  |
| 2 | Переносим упор и развиваем усилие для движения кости плеча вниз. При этом движения как такового не происходит, но теперь - мышцы с другой стороны плеча напрягаются |  |  |  |
| 3 | Прилагаем усилие для движения кости плеча влево |  |  |  |
| 4 | Прилагаем усилие для движения кости плеча вправо |  |  |  |
| 5 | Кулак направляем к полу и прилагаем усилие скрутки для вращения кости внутрь |  |  |  |
| 6 | Кулак направляем к полу и прилагаем усилие скрутки для вращения кости наружу |  |  |  |
