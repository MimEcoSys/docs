# Моделирование: Лестница усилий

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения наклон создаем преднатяжение. Развиваем усилия до движения бедра к тазу, добавляем одно поисковое усилие, следом еще одно…3,4,5. Сумму усилий держим 5-4-3-2-1, отпускаем. |  |  |  |
| 2 | Соберите 10 поисковых усилий (используя медленные атаки, если будут прорываться резкие увеличения усилий) |  |  |  |
| 3 | Соберите 20 поисковых усилий (используя медленные атаки, если будут прорываться резкие увеличения усилий) |  |  |  |
| 4 | Подготовка к нагрузкам в упоре – стоя у стены с поднятыми вверх руками, лицом к стене упираемся в стену, проходим возникшее ограничение по памяти, и выполняем лестницу усилий до 20 поисковых усилийИз положения упор 45 градусов к стене, создаем преднатяжение. |  |  |  |
| 5 | Подготовка к нагрузкам в упоре – из предыдущего положения, переставляем руку так, чтобы получить упор с поворотом к стене в 45 градусов, проходим возникшее ограничение по памяти, и выполняем лестницу усилий до 20 поисковых усилий |  |  |  |
| 6 | Подготовка к нагрузкам в упоре – из предыдущего положения, переставляем руку так, чтобы перейти в упор боковой, проходим возникшее ограничение по памяти, и выполняем лестницу усилий до 20 поисковых усилий |  |  |  |
| 7 | Подготовка к нагрузкам в упоре – из предыдущего положения, переставляем руку так, чтобы получить упор с поворотом к стене в 45 градусов, проходим возникшее ограничение по памяти, и выполняем лестницу усилий до 20 поисковых усилий |  |  |  |
| 8 | Подготовка к нагрузкам в упоре – из предыдущего положения, переставляем руку так, чтобы получить упор спиной, проходим возникшее ограничение по памяти, и выполняем лестницу усилий до 20 поисковых усилий |  |  |  |
