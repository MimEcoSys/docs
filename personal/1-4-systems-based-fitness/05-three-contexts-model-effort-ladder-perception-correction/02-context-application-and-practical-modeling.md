# Моделирование: Контексты

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Используем позу стоя, с поднятыми вверх руками, моделируем контекст веса на рычаге практикой лодочек:А) лежа на полу спиной, отрываем от пола одновременно руки и ногиБ) лежа на полу на правом боку, отрываем от пола одновременно руки и ногиВ) лежа на полу на левом боку, отрываем от пола одновременно руки и ногиГ) лежа на полу на животе, отрываем от пола одновременно руки и ногиВ каждом положении находим диапазон рабочего усилия – ту амплитуду, в которой удается управлять тканевыми объемами – выстраивать сплошное и равносильное усилие |  |  |  |
| 2 | Используем позу стоя, с поднятыми вверх руками, моделируем контекст пассивного растяжения практикой вывешивания. С использованием фитбола, табурета, пуфика с мягкими углами:А) лежа на табурете спиной, с пассивно свисающими руками и ногамиБ) лежа на табурете правым боком, с пассивно свисающими руками и ногамиВ) лежа на табурете левым боком, с пассивно свисающими руками и ногамиГ) лежа на табурете животом, с пассивно свисающими руками и ногамиВ каждом положении находим диапазон рабочего усилия – ту амплитуду, в которой удается управлять тканевыми объемами – выстраивать сплошное и равносильное усилие |  |  |  |
| 3 | Используем позу стоя, с поднятыми вверх руками, моделируем контекст весовой нагрузки практикой упоров:А) стоя с поднятыми вверх руками, упираемся двумя руками в стену, лицом к стенеБ) стоя с поднятыми вверх руками, левым боком к стене, упираемся двумя руками в стенуВ) стоя с поднятыми вверх руками, правым боком к стене, упираемся двумя руками в стенуГ) стоя с поднятыми вверх руками, упираемся двумя руками в стену, спиной к стенеВ каждом положении находим диапазон рабочего усилия – ту амплитуду, в которой удается управлять тканевыми объемами – выстраивать сплошное и равносильное усилие |  |  |  |
| 4 | Увеличение нагрузки в упоре достигается перемещением рук по стене вниз, ближе к полу, при этом увеличивая расстояние от ног до стены, при необходимости, достигая положения подобного планке с упором на стену или на пол |  |  |  |
| 5 | Удалось ли выделить разницу в амплитудах в диапазоне управляемых усилий и амплитудах значительно больших, но без доступа к управлению тканевыми объемами? (если мы занимаемся регуляцией, то может быть неожиданно рано, останавливать нагрузку, чтобы сохранить регуляцию, и это нужно держать во внимании) |  |  |  |
