# Моделирование: Надколенник

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Сидя на полу, от лобковой кости глазами проводим диагональ к надколеннику. От переднего края подвздошной кости к надколеннику проводим вторую диагональ. Для приема нужна средняя линия между диагоналямиПальцами очень аккуратно оттягиваем надколенник по средней линии ровно к стопе (нужно усилие до движения наколенника. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 2 | Сидя на полу, от лобковой кости глазами проводим диагональ к надколеннику. Пальцами очень аккуратно оттягиваем надколенник по линии диагонали к стопе (нужно усилие до движения наколенника. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 3 | Сидя на полу, от переднего края подвздошной кости к надколеннику проводим диагональ. Пальцами очень аккуратно оттягиваем надколенник по линии диагонали к стопе (нужно усилие до движения наколенника. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 3 | Проверяем амплитуду с помощью тестовых приемов |  |  |  |
