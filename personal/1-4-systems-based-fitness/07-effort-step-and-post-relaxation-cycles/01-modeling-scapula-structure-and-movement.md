# Моделирование: Лопатка

Для выполнения приемов понадобится пространство для работы лежа. Готовим подушки/свернутые одеяла/коврики для облечения позы и опоры для рук.

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча), подкладываем под плечо и руку подушку. Развиваем усилие до давления кулаком в подушку. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 2 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча), подкладываем под плечо и руку подушку. Развиваем усилие до поднятия кулака от подушки. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 3 | Из положения лежа, рабочую руку укладываем возле головы (локоть в районе плеча), подкладываем под плечо и руку подушку. Развиваем усилие до опускания локтя к ребрам. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 4 | Из положения лежа, рабочую руку сгибаем в локте и поднимаем локтем вверх, перед собой. Развиваем усилие до вытягивания локтя к потолку. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 5 | Из положения лежа, рабочую руку сгибаем в локте и поднимаем локтем вверх, перед собой. Развиваем усилие до вытягивания локтя к потолку вперед. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 6 | Из положения лежа, рабочую руку сгибаем в локте и поднимаем локтем вверх, перед собой. Развиваем усилие до вытягивания локтя к потолку вперед и вниз. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 7 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча). Развиваем усилие до подтягивания нижней части лопатки к груди. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 8 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча). Развиваем усилие до подтягивания нижней части лопатки к тазу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 9 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча). Развиваем усилие до подтягивания нижней части лопатки к тазу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
