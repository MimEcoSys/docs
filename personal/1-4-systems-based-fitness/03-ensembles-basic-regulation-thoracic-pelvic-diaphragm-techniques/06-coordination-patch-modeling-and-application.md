# Моделирование: Координационная заплатка

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Назовите костные этажи (возле каких костей) регулярно ощущаются сопротивления в повороте или прогибе |  |  |  |
| 2 | Какими приемами удается проработать сопротивление? (не менее двух) |  |  |  |
| 3 | Создайте координационную заплатку:1. Из положения прогиб или поворот (что актуальнее) находим положение, в котором проявляется сопротивление2. Перечисленные в предыдущем действии приемы выполняем одновременно – развиваем усилие и держим на счет 5-4-3-2-1. Отпускаем3. Повторяем 3 раза и запоминаем единое тканевое чувство дорасслабления (гифка координационной заплатки) |  |  |  |
| 4 | Попробуйте применить координационную заплатку:В самом начале прогиба или поворота начинаем обмякать ансамбльДоводим прогиб или поворот до доступной на текущий момент амплитуды, без паузы на сопротивлениеОцениваем интенсивность напряжения на каждом костном этаже (нужно одинаковое) |  |  |  |
| 5 | Создайте координационные заплатки для всех прогибов (вперед, назад, вправо, влево) и поворотов (вправо и влево) |  |  |  |
