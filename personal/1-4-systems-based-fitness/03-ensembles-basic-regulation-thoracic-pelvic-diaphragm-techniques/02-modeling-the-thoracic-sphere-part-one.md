# Моделирование: Грудная сфера, часть 1

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до втягивания живота до того, как возникает отклик на движение в районе спины. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 2 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до расширения ребер до отклика на спине (для тренировки, ставим руки на ребра по бокам, с двух сторон, делаем глубокий вдох и держим во внимании, как работает мышечный компонент, который расширяет ребра для вдоха, делаем два-три глубоких вдоха и пробуем расширить ребра без вдоха). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 3 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до надувания или выпячивания живота до отклика на спине. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 4 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до крика до отклика на спине (для тренировки, берем подушку и кричим в нее, удерживая во внимании мышечный компонент – что давит тянет для того, чтобы получился крик). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны. Пробуем по памяти сделать дорасслабление |  |  |  |
| 5 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до икания до отклика на спине. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны. Пробуем по памяти сделать дорасслабление |  |  |  |
| 6 | Поворот (или прогиб) до положения преднатяжения. Развиваем усилие до смеха до отклика на спине. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления, запоминаем процесс дорасслабления, для каждой стороны. Пробуем по памяти сделать дорасслабление |  |  |  |
