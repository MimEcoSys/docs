# Моделирование: Вывешивания

Для приемов понадобятся тумбочки/табуретки/фитболы.

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения лежа, на тумбочке, прорабатываем перетянутые фрагменты ленты, добившись сплошного равносильного натяжения. |  |  |  |
| 2 | Из положения лежа на тумбочке, набираем усилие для выпрямления, через вытяжение. Усилие на вытяжение развиваем до ленты, и проверяем до какой высоты можно поднять руки и ноги управляемым усилием. Тренируем равномерный набор усилий - 4,10,20 усилий. |  |  |  |
| 3 | Из положения лежа на тумбочке, набираем усилие для выпрямления, через стягивание всех костных этажей. Усилие на стягивание развиваем до ленты, и проверяем до какой высоты можно поднять руки и ноги управляемым усилием. Тренируем равномерный набор усилий - 4,10,20 усилий. |  |  |  |
| 4 | Из положения лежа на тумбочке, набираем усилие для выпрямления, через скрутку влево. Тренируем равномерный набор усилий - 4,10,20 усилий. |  |  |  |
| 5 | Из положения лежа на тумбочке, набираем усилие для выпрямления, через скрутку вправо. Тренируем равномерный набор усилий - 4,10,20 усилий. |  |  |  |
| 6 | Из положения лежа на тумбочке, набираем усилие для выпрямления, через усилие для прогиба. Тренируем равномерный набор усилий - 4,10,20 усилий. |  |  |  |
