# Моделирование: Глазодвигательные мышцы

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Тест – медленно на счет 1-2-3-4 делаем круг глазами, как можно плавнее и пользуясь циферблатом определить, в каком положении глаз проскакивает движение рывком м не планов.Делаем три круга, записываем результат |  |  |  |
| 2 | Из положения поворот, создаем преднатяжение затылочной области и области шеи. Развиваем усилие до движения глаз вправо (до отклика в шее или в горле, если отклика нет – завести глаза чуть больше, используя усилие для движения). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 3 | Из положения поворот, создаем преднатяжение затылочной области и области шеи. Развиваем усилие до движения глаз влево (до отклика в шее, если отклика нет – завести глаза чуть больше, используя усилие для движения). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 4 | Из положения поворот, создаем преднатяжение затылочной области и области шеи. Развиваем усилие до движения глаз наверх (до отклика в шее, если отклика нет – завести глаза чуть больше, используя усилие для движения). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 5 | Из положения поворот, создаем преднатяжение затылочной области и области шеи. Развиваем усилие до движения глаз вниз (до отклика в шее, если отклика нет – завести глаза чуть больше, используя усилие для движения). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 6 | Пробуем альтернативное исходное положение - лежа на спине, поворачиваем голову для создания преднатяжения. Развиваем усилие до движения глаз вправо (до отклика в шее, если отклика нет – завести глаза чуть больше, используя усилие для движения). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 7 | Пробуем альтернативное исходное положение - лежа на спине, поворачиваем голову для создания преднатяжения. Заводим глазные яблоки в сторону до упора, и удерживаем взгляд, выбрав себе ориентир. Развиваем усилие до движения глаз обратно (в противоположную сторону). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 8 | Пробуем альтернативное исходное положение - лежа на спине, поворачиваем голову для создания преднатяжения. Заводим глазные яблоки в сторону до упора, и удерживаем взгляд, выбрав себе ориентир. Развиваем усилие до движения глаз вверх. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |

Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Возвращаем глаза в исходное положение и закрываем (можно ладонью). Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 11 | Из положения поворот, создаем преднатяжение затылочной области и области шеи. Выносим за зону фокусировки тонкую ниточку – шерстинку и одновременно отдаляем шерстинку и развиваем усилие для фокусировки на шерстинке.
