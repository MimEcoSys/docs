# Зачем нужен предмет интереса

Предмет интереса нам нужен, чтобы мы потом смогли сказать, каким **методом** его описывать (viewpoint). Например, метод описания цены::характеристика может быть **правилами** составления сметы, в рублях, в долларах или "условных единицах". Этот метод описания нужно будет использовать, чтобы описанный при его помощи предмет интереса (цена) был потом обсуждён разными ролями (продавцом и покупателем). Тем самым дискуссия о методе описания цены (как моделировать цену, как лучше её описывать, каким способом отразить знания о цене как характеристике системы) будет отличаться от дискуссии о значении цены, то есть о том, "как снизить цену" и "как поднять цену", хотя обе эти дискуссии оказываются существенно связанными (выбор метода описания обычно влияет на переговорную позицию одной из сторон: разные методы описания интереса удобны для продвижения разных предпочтений).

Когда мы только что разделили одну сложную дискуссию по важной характеристике на две более простых (по методу описания и по уторговыванию предпочтений), задача стала немного проще — это и есть цель системного мышления. Разделение в мышлении ролей, предметов их интереса/характеристик систем, интересов/предпочтений в значениях характеристик систем упрощает достижение договорённостей между ролями в проекте, облегчает коллективное выполнение проектов по созданию систем.

Главное, для чего нам нужны роли — это для обсуждения методов их работы, требующих каких-то предпочтений в важных характеристиках затрагиваемых этими методми работы систем. Мы должны отвечать на вопросы ролей по предметам их интереса, готовя какие-то описания системы и проекта, связанного с системой теми способами описания, которые мы согласовали. В ряд "роль", "предмет интереса", "предпочтение" добавим ещё два понятия:

- Ролевое описание (view)
- Метод описания (viewpoint)

Подготовка ролевых описаний (view) по каким-то согласованным методам описаний (viewpoints) позволяет удерживать во внимании и список ролей, и важные для них характеристики, и предпочтения по значению этих характеристик. Эти описания становятся предметом для обсуждения — системное мышление коллективно, оно подразумевает непрерывное согласования между самыми разными ролями и предназначено для структурирования этого согласования.
