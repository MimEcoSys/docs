# Вопросы. Системное разбиение и эмерджентность

Что является частью объекта «стол из гостиной»?

2. Троллейбус

4. Городская дорожная сеть

6. Городская энергосистема
7. Тяговая подстанция
8. Городская электростанция

1. Надсистема-система-подсистема
2. Класс-подкласс-член класса
3. Множество-подмножество-элемент множества
