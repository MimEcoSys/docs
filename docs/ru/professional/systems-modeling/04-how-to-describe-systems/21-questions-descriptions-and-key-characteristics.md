# Вопросы. Описания и важные характеристики

Царь послал в чужеземные края трёх мастеров, чтобы каждый из них описал заморскую самоходную тележку. Что должны спросить мастера, чтобы не попасть впросак?

1. спросить у царя, какой метод описания они должны выбрать
2. спросить у царя, что именно он хочет знать
3. опросить, кроме царя, всех бояр да дьяков - какой у них предмет интереса к тележке
4. узнать друг у друга, какая специализация каждого мастера (сперва каждый мастер знает только свою)
5. одно ли от них описание ждут, или три — от каждого мастера по одному независимому
6. на сколько страниц должно быть описание
7. спросить, кто будет читать привезённое описание
8. есть ли где ещё другие такие же тележки
9. на пергаменте им описывать, на бересте или на бумаге

При проектировании источника питания для СВЧ модуля инженер должен уложиться в указанные конструктором габариты. Какой метод описания габаритов может использовать конструктор, передавая задание инженеру?

1. Эскиз компоновки СВЧ модуля на салфетке, с указанием габаритов в см отдельной строкой
2. Вылепленный из пластилина в масштабе 1:5 макет СВЧ модуля
3. Чертеж СВЧ модуля с источником питания, выполненный по ГОСТам
4. Показ габаритов модуля на пальцах
5. Продиктовал габариты модуля по телефону
6. Табличка с габаритами модуля в мм
