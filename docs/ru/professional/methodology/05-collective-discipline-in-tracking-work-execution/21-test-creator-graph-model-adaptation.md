# TEST Адаптация модели графа создателей

Менеджер проекта думает, как ему отслеживать прогресс разработки сложной инженерной системы. Ему нужно отслеживать для этого:

1. Состояние альф «Описание целевой системы» и «Воплощение целевой системы»
2. Отчёт о затраченных инженерами ресурсах и времени выполнения работ
3. Протоколы обсуждений инженерами встреченных трудностей на научно-техническом совете
4. Состояние альфы «Описание организации проекта»

На вопрос «Как дела?» команда проекта рассказала, что они уже трижды достигали состояния «Готово» для альфы «Воплощение целевой системы», но потом откатывались к состоянию «Демонстрируема». Как это возможно?

1. Команда что-то путает, пешки назад не ходят
2. Команда несколько раз не проходила испытания в ходе инженерного обоснования, поэтому переделывала готовую систему
3. Возвраты к «Демонстрируемо» состоялись за пределами проекта, во внеурочное время

Команда проекта договорилась, что, вместо отслеживания для альфы «Работа» состояний «Инициирована», «Подготовлена», «Начата», «Под контролем», «Закончена», она будет использовать другой набор, более привычный для менеджера проекта (он ссылается на стандарт проектного управления, в котором используются другие названия, и менеджер проекта собирается использовать этот стандарт, а не идеи из стандарта OMG Essence). Можно ли так делать?

1. ОК, команда в своём праве
2. Нет, стандарты нужно соблюдать целиком: если используете язык OMG Essence, то и все названия должны быть из него, а если иной стандарт проектного управления — то из него, не путайте людей.
3. ОК, если это разрешит высшее руководство
4. Нет, команда потеряет возможность обсуждать работы

На совещании команды развития и проекта оценили состояние команды проекта как уже «Сформирована», но ещё не «Сотрудничает». Что им нужно сделать, чтобы перейти в новое состояние?

1. Ничего, пройдёт время, все притрутся друг к другу, можно будет отрапортовать результат — ничего специального делать не нужно.
2. Наметить и выполнить какие-то работы с альфой «Команда проекта»

Если подальфа продвинулась по её состояниям, или даже откатилась назад, что, скорее всего, произошло с её (над)альфой?

1. Ничего, они никак не связаны, это просто удобный способ группировки отслеживаемых в проекте объектов
2. Ничего, они ведь специально создаются для отражения разных состояний разных объектов в проекте
3. Состояние надальфы тоже изменилось, но, возможно, не так сильно, чтобы гарантированно перейти в следующее или предыдущее состояние
4. Надальфа гарантированно перешла в следующее состояние
