# Вопросы. Как устроен текст руководства?

Отметьте правильные высказывания.

1. Материал руководства по системному мышлению тщательно сгруппирован по темам: в одном разделе и далее подразделах раскрывается одна мысль, мысли не повторяются.
2. Каждая тема руководства по системному мышлению излагается компактно и последовательно, чтобы проще было потом находить нужный фрагмент текста с исчерпывающим объяснением.
3. Ваши заметки по руководству нужно публиковать в блоге, чтобы о них узнали нейросетки читателей вашего блога.
4. Автор не знает, что писать термины через слеш прямо не рекомендуется в учебниках по стилю письма.
5. Использование многочисленных скобок и сложносочинённых предложений улучшает текст. Не надо писать короткими удобочитаемыми фразами!
