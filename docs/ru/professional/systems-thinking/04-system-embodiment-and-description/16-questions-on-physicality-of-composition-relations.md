# Вопросы на физичность отношения состава

Джон написал несколько примеров для руководства по системному мышлению, вы должны проверить их и отметить правильные.

1. Пример отношения состава: «Документация состоит из трёх томов, каждый том состоит из трёх тетрадей».
2. Пример отношения состава: «Описание состоит из рассказа по трём темам, каждая из которых содержит три сюжета»
3. В спектакле есть три акта, каждый из которых состоит из трёх явлений.
4. Крепление состоит из трёх отверстий с резьбой М3, разнесённых по треугольнику на 6 см друг от друга.
5. Пентапризматор состоит из трёх модулей, каждый из которых состоит на учёте в пентарегистре
6. Люди клана Среднезубых состояли из воинов, торговцев и юристов, а воины в свою очередь состояли из лучников, кавалеристов и артиллеристов.
7. Треугольник состоит из трёх сторон, а каждая сторона состоит из двух точек-вершин треугольника, соединённых отрезком прямой.
