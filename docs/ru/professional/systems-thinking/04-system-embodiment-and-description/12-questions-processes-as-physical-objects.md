# Вопросы. Процессы как физические объекты

Какие утверждения верны для объекта, являющегося в четырехмерном пространстве-времени процессом создания чертежа стола?

1. Этот объект обладает протяженностью только во времени, в пространстве он ничем не представлен;
2. Этот объект обладает протяженностью во времени и представлен в пространстве самим чертежом;
3. Этот объект обладает протяженностью во времени и совпадает в период рисования со всеми объектами, задействованными в рисовании (лист, карандаш, линейка, рисующий инженер).
4. Этот объект обладает протяженностью во времени и представлен в пространстве рисующим инженером
5. Этот объект обладает протяженностью во времени и совпадает в период рисования со всеми объектами, задействованными в рисовании, а также со всеми созданными по этому чертежу столами до конца их жизненного цикла.
6. этот объект — система
