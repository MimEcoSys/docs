# Задание по следованию «мантре системного мышления»

Проставьте отметку о выполнении:

1. Выполните для своего проекта пункты мантры системного мышления, взяв какое-то одно звено (создатель-создаваемая система) в цепочке создания от вас-создателя до целевой системы (отдельно пропишите этот путь на графе создателей от вас-создателя до целевой системы и выберите пару смежных узлов графа, где одна система создаёт другую). Напишите пост с рассуждениями по пунктам мантры для этого звена. Отметьте в посте, о чём пришлось подумать впервые (то есть не задумывались об этом раньше), если не пропускать шаги рассуждения. Что надо поменять в проекте, чтобы использовать результаты прохождения этого системного рассуждения по системной мантре? Что и кому надо предпринять, чтобы повысить шансы успешности проекта? В частности, что надо предпринять лично вам?
