# Моделирование: аннотирование типами с использованием нотации ::

Для предложений из таблички сделайте дубль, указав типы всех объектов и отношений, как показано в первой строке.

| Номер п/п | Без типов | С типами |
| --- | --- | --- |
| Пример | Летит самолёт. | Летит::функция самолёт::система. |
| 1. | Молоток бьёт по гвоздю. |  |
| 2. | Вася работает инженером |  |
| 3. | Компьютер состоит из корпуса, материнской платы, клавиатуры и экрана. |  |
| 4. | Роза — это цветок. |  |
