# Задание 3.2.

Продолжите выполнение задания 3.1. Лучше продолжить работу в парах или в маленьких группах 3-4 человека.

1. Опишите найденные причинно-следственные связи в виде пар «причина – следствие».
2. Поищите ещё пары «причина-следствие», важные для вашего объяснения в контексте выдвинутых гипотез.
3. Укажите для каждой пары, какой типы причины вы предполагаете (необходимая, достаточная, способствующая).
4. Обязательно придумайте хотя бы один пример контрфактического рассуждения по теме вашего исследования (возможно, ещё расширьте список причин и сделствий), и опишите отдельно возможный мир, соответствующий этому рассуждению.
5. Эссе о продолжении исследования с примерами написано и размещено в клубе Мастерской. Для подробного описания результатов вашей работы сделайте табличный формат. Вы продолжите выполнения этого задания после изучения следующего раздела.
