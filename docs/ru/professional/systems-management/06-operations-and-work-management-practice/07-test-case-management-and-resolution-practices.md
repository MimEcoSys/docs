# TEST Управление кейсами

На чём фокусируется кейс?

1. На действиях
2. На предмете, над которым производятся действия
3. на исполнителях действий с каким-либо предметом
4. на уникальности и однократности выполнения кейса

Почему приложения low code могут не оправдывать ожиданий?

1. они работают очень медленно
2. софт low code очень дорогой
3. хорошо работают на простых демонстрациях с малым числом объектов, но всё равно требуют профессионального программирования для массовой работы (то есть свойство low code не выполняется)
4. они используют визуальные языки описания процессов, которые ужасны при росте объёма программ
