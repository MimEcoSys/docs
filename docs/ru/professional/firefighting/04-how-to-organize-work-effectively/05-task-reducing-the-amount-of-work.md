# R1.3:Tasks2 - Задание: Уменьшаем число выполняемых работ

Постараемся сбалансировать вход и выход работ, то есть определить и не превышать вашу реальную способность выполнить работы/operational capacity. Начнём оценивать, сколько вы можете сделать за день, и не брать лишнее (или не брать слишком мало!).

Предварительно посмотрите на свой список рабочих проектов. Если ли среди них особенно выгодные? Есть ли среди них те, которые сейчас неактуальны для компании и только съедают время? Можно ли их: ускорить, отложить, убрать.

1. Определите по таблице хронометража, что из реально выполнявшихся работ можно было: → Не делать? → Делегировать? → Ускорить выполнение (автоматизировать, сделать иначе)?
2. Попробуйте ежедневно, перед началом работы, в таблице с очередью/планом отметить: → Что вы будете делать сегодня. → Что вы перенесете-отложите, и на когда (для этого мы заводили столбцы Планового начала и окончания работы). → Что вы делегируете (для таких работ вы должны будете дополнить план работами по методу делегирования, обсуждавшемуся выше!). → Что вы выкините из плана
3. По окончании первой недели опишите результат. Опубликуйте пост в Aisystant (для проходящих резидентуру с наставниками) либо в клубе МИМ.
