# R3.2:Tasks1 - Формулируем утверждения про объекты разных типов

Придумайте осмысленные фразы, использующие указанные в вопросах словосочетания так, чтобы их употребление указывало на заданный после словосочетания тип.

Например:

- Во фразе «Вчера мой рабочий день длился до 20:00» употребление словосочетания «рабочий день» указывает на тип «индивид».

- Во фразе «Рабочий день сотрудника должен составлять не более 8 часов» употребление словосочетания «рабочий день» указывает на тип «концепт».

1. «организация» - индивид
2. «организация» - концепт (пример 1)
3. «организация» - концепт (пример 2)
4. «компьютерная программа» - индивид
5. «IT-решение для фирмы» - концепт (пример 1)
6. «IT-решение для фирмы» - концепт (пример 2)
7. «сотрудники» - индивиды
8. «сотрудники» - концепт (пример 1)
9. «сотрудники» - концепт (пример 2)
10. «работа» - индивид
11. «работа» - концепт (пример 1)
12. «работа» - концепт (пример 2)
