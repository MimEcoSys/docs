# R3.2:Mod2 - Оцениваем плотность концептуального пространства

Перед выполнением этого задания желательно поговорить о своей предметной области и её объектах с коллегами, находящимися в разных ролях, отличающихся от вашей роли. Найдите хотя бы две разные роли (свою и чью-то ещё, лучше - больше), использующие объекты вашей предметной области: в методах одной роли объект может быть определен достаточно однозначно, но при анализе другими ролями размытие воплощений этого концепта может стать заметным.

Для категорий из «R3.1:Mod2 - Расширяем модель предметной области» (не для индивидуальных объектов!) укажите плотность концептуального пространства, по трём градациям: плотное, среднее, разреженное.

| Объект/Концепт (только категории) | Какими ролями используется | Плотность концептуального пространства (плотное, среднее, разреженное). Поясните ответ, желательны примеры. | Нужно ли что-то делать сделать для улучшения коммуникации по поводу этого объекта? Что? |
