# R3.4:Tasks4 - Готовим описание

Проделайте работу по моделированию/подготовке описания, опишите выбранный фрагмент предметной области или просто фрагмента мира. Для этого напишите текст, разработайте шаблон текста, анкету, чек-лист, постройте диаграмму, сделайте набор табличек с информацией, спроектируйте набор табличек для заполнения, разработайте экранные формы. Отметьте выполнение и прокомментируйте каждый этап:

1. Результат достигнут - описание подготовлено, его ценность понятна.
2. Сделан набор скриншотов, иллюстрирующих получившееся описание.
3. Опубликован пост в клубе МИМ, рассказывающий о процессе сбора информации и о подготовке описания. Пост проиллюстрирован получившимися скриншотами. В пост включены впечатления от проделанной работы и возникшие в её процессе соображения (мышление письмом).
4. Зафиксированы затраты времени на основные работы по подготовке описания (в посте в клубе МИМ, или в поле ниже).
