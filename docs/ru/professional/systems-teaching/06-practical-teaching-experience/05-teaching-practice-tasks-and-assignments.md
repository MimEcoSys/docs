# Задания по преподавательству

Для вашего проекта обучения в coda.io:

1. Создайте и заполните в coda.io таблицы подальф целевого мастерства студенческой группы, где каждая подальфа представляет собой мастерство отдельного студента. В качестве шаблона используйте состояния и контрольные вопросы, спроектированные в упражнении по альфе мастерства в Aisystant.
2. Напишите из роли преподавателя пост о вашем проекте обучения. Что и кому будет говорить преподаватель в вашем проекте? Отразите это в посте.
