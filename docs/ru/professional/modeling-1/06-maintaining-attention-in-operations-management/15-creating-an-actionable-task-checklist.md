# R2.6:Tasks5 - Создаём чеклист

Завершающим заданием этой резидентуры будет создание чеклиста для удержания внимания. Желательно разработать этот чек-лист для команды/коллектива, занятого в проекте. Но если у вас нет сейчас такой команды, разработайте чеклист для себя лично. Результаты выполнения этого задания могут быть размещены вам в Aisystant, но лучше оформить их в виде записи в вашем блоге в клубе МИМ. Это задание должно стать детализацией графа создателей, описанного вами ранее при выполнении задания «R2.6:Tasks4 - Путешествие объекта через предприятие».

1. Возьмите полученную вами модель путешествия объекта, выберите наиболее знакомый вам узел графа создателей, опишите его, назовите - какая роль осуществляет взаимодействие с объектом в этом узле и по каким методам агент в этой роли действует.
2. Опишите, в каком состоянии должен находиться объект в результате взаимодействия.
3. Запишите контрольные вопросы, которые позволят оценить, выполнены ли нужные действия по методу и пришел ли объект в нужные состояния. Не забудьте включить вопросы, которые позволят провести и необходимые измерения изменений.
4. Обсудите полученный чеклист с командой, отметьте полученные замечания и поправки.
5. Опишите, где в коллективном (или личном) экзокортексе будет размещён полученный чеклист.
6. Проведите обучение использованию чеклиста.
