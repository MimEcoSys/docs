# R2.6:Mod1 - Определяем состояния предметов метода

Выберите один из методов, который вы применяете для выполнения задач. Назовите важнейшие состояния минимум для двух предметов этого метода (объектов внимания). Приведите примеры полных имён темпоральных частей этих объектов в указанных состояниях, отражающие особенности применения метода для конкретных индивидуальных объектов в вашей предметной области.
