# Домашнее задание

1. Выполнить все приемы дня, для обеих сторон, добиваясь увеличения амплитуд в упорах. Собираем подробную гифку для ленты (от ладоней до стоп)
2. Пробуем готовить поисковые усилия - +4+10+20 поисковых усилий лентой
3. Учим гифку для ленты поисковым шагом набора усилий
4. Учим гифку для ленты поисковым шагом обмякания – отпускания усилий шагами
5. Во время выполнения приемов проговариваем выполняемые действия вслух, для лучшего наведения внимания (пример - работаю над лентой, в упоре, параметры сплошноты и равномерности нарушает такой-то этаж, возвращаюсь на пол, выполняю регуляцию, продолжаю отстраивать параметры ленты)
6. Разучиваем гифки для приемов, которые помогают увеличить амплитуды (бывшие именно вашими ограничениями в амплитуде).
7. Два раза перечитать таблицу с костными этажами, ткнуть пальцем любую часть тела и назвать костный этаж.
