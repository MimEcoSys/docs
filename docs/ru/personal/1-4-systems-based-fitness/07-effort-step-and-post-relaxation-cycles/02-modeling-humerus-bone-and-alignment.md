# Моделирование: Плечевая кость

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча), подкладываем под плечо и руку подушку. Развиваем усилие до давления плечом в пол. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 2 | Из положения лежа, рабочую руку укладываем возле головы (локоть выше плеча), подкладываем под плечо и руку подушку. Развиваем усилие до поднятия плеча к потолку. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
