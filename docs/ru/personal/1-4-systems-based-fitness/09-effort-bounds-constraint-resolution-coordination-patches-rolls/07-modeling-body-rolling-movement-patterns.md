# Моделирование: Перекаты

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения лежа на полу, перекатываемся в сторону «бревном» - положение грудной клетки и тазовых костей остаются одинаковыми относительно друг друга |  |  |  |
| 2 | Из положения лежа на полу, двигаемся в сторону «спиралью» - первыми в движение включаются тазовые кости, грудная клетка догоняет |  |  |  |
| 3 | Из положения лежа на полу, с выпрямленной в сторону головы рукой, двигаемся в противоположную руке сторону «спиралью» - усилие только в руке и регулируя положением руки натяжение:Рука вверхуРука в области середины реберРука в области низа реберРука в области тазаДержим во внимание передачу в теле натяжения в зависимости от положения руки. Все замеченные ограничения отключаем имеющимися гифками |  |  |  |
| 4 | Из положения лежа на полу, с руками, лежащими вдоль позвоночника к тазу, двигаемся в сторону «спиралью» - усилие только в ноге и регулируя положением ноги натяжение:Движение из верхней части ноги (тазовыми костями)Движение из нижней части ноги (тазовые кости вытягиваются за счет движения ноги вперед вниз)Держим во внимание передачу в теле натяжения в зависимости от положения ног. Все замеченные ограничения отключаем имеющимися гифками |  |  |  |
| 5 | Из положения вывешивания (с использованием подушек) выполняем спиральный перекат с боку, полубоку, с живота, со спины |  |  |  |
