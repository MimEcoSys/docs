# Моделирование: Опорность и соскальзывание

В вертикальном упоре – меньше нагрузки. При необходимости усложнения, руки можно переставлять, ближе к полу (планка – частный случай развития упора). Можно уменьшать количество опор (отрывать от стены руки или от пола ноги).

С ростом нагрузки более проявляется параметр – опорность или соскальзывание костей. Чем больше нагружаете тканевые объемы, тем больше нужно опоры.

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Подбираем упор в границе управляемых усилий. Снимаем нагрузку левой ноги и обмякаем левую часть тела. Отслеживаем выход из усилия – разгружаемую ленту |  |  |  |
| 2 | Из положения предыдущего приема начинаем разгружать правую ногу, ступенями – 10%, 20%, 30%, 40%, 50%. Отличаются усилия в правой и левой половине тела? |  |  |  |
| 3 | Из положения предыдущего приема ищем два лично своих положения тела 1) «опорное» и 2) «соскальзывающее». Если кости в соскальзывающем положении, мы в минимальном усилии упираемся в соскальзывание и уменьшать усилие больше не можем. Кости в опорном положении, позволяют более глубокое мышечное расслабление, и нижняя планка лестницы усилий становится ниже. |  |  |  |
| 4 | В разных вариантах упоров (боком, передом, спиной), с разным количеством опор (4-3-2 точки) найти опорное положение костей |  |  |  |
