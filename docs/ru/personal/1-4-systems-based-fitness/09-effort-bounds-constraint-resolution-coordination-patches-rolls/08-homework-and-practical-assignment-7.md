# Домашнее задание

1. Уточнение лент – разбитие вокселей на приемы, уточнение вокселей, пересборка новых лент с новым составом
2. Уже имеющимися лентами работать с изменением нагрузки
3. Во время выполнения приемов проговариваем выполняемые действия вслух, для лучшего наведения внимания (пример - работаю над лентой, в упоре, параметры сплошноты и равномерности нарушает такой-то этаж, возвращаюсь на пол, выполняю регуляцию, продолжаю отстраивать параметры ленты)
4. Разучиваем гифки для приемов, которые помогают увеличить амплитуды (бывшие именно вашими ограничениями в амплитуде).
5. Два раза перечитать таблицу с костными этажами, ткнуть пальцем любую часть тела и назвать костный этаж.
