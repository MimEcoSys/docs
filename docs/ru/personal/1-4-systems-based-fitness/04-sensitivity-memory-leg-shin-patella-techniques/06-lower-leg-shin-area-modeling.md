# Моделирование: Голень

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Выполняем тест для области голени – прижать мысок к пятке (Золушка примеряет туфельку). Тест будем использовать для проверки результатов (можно обвести на листе бумаги результат) |  |  |  |
| 2 | Второй тест. Рабочую ногу, без веса отставляем вперед, чуть сгибаем, ладонью фиксируем колено и проворачиваем кости голени вправо и влево (скрутка от стопы до колена, стопа и мысок не отрываются от пола) |  |  |  |
| 3 | Третий тест. Садимся на поджатые ноги с выпрямленным подъемом, насколько получается. Отмечаем – удалось ли сесть полностью |  |  |  |
| 4 | Для создания преднатяжения вес переносим на нерабочую в приеме ногу. Рабочей, свободной, ногой толкаемся пятками от пола (выталкиваем стопой таз от пола). Развиваем усилие до разгибания фаланг пальцев ног без ногтей. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 5 | Для создания преднатяжения вес переносим на нерабочую в приеме ногу. Рабочей, свободной, ногой толкаемся пятками от пола (выталкиваем стопой таз от пола). Развиваем усилие до разгибания фаланг пальцев ног с ногтями (удобнее из положения разогнутых пальцев ног – «доразогнуть к подъему»). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 6 | Для создания преднатяжения вес переносим на нерабочую в приеме ногу. Рабочей, свободной, ногой толкаемся пятками от пола (выталкиваем стопой таз от пола). Развиваем усилие до приведения стопы к ноге (поднятию мыска от пола). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 7 | Альтернативный вариант создания преднатяжения. Вес переносим на рабочую в приеме ногу. Выставляем ее немного вперед. Весовую нагрузку смещаем к основанию мизинца (по очереди пробуем смещать вес на каждый из пальцев ноги) |  |  |  |
| 8 | Создаем преднатяжение в альтернативном варианте. Развиваем усилие до прижимания фаланг без ногтей к полу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 9 | В положении преднатяжения (любой вариант) развиваем усилие до скребка ногтями по полу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 10 | В положении преднатяжения (любой вариант) развиваем усилие до вставания на мысок. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 11 | В положении преднатяжения (любой вариант) развиваем усилие до вращения пальцев внутрь. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 12 | В положении преднатяжения (любой вариант) развиваем усилие до вращения пальцев наружу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 13 | В положении преднатяжения (любой вариант) развиваем усилие до вращения пяткой внутрь. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 14 | В положении преднатяжения (любой вариант) развиваем усилие до вращения пяткой наружу. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 15 | В положении преднатяжения (любой вариант) развиваем усилие до вращения стопы на внешнее ребро. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 16 | В положении преднатяжения (любой вариант) развиваем усилие до вращения стопы на внутреннее ребро. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 17 | В положении преднатяжения (любой вариант) развиваем усилие до перемещения стопы в сторону наружу (разгребаем песок). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 18 | В положении преднатяжения (любой вариант) развиваем усилие до перемещения стопы в сторону внутрь. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 19 | В положении преднатяжения (любой вариант) развиваем усилие до растопыривания пальцев. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 20 | В положении преднатяжения (любой вариант) развиваем усилие до сжимания пальцев друг с другом пальцев. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 21 | Повторяем тестовые приёмы, измеряем амплитуды |  |  |  |
