# Моделирование: Ансамбль ног, часть 1

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |

| 1 | Наклон вперед, с упором руками на стул. Делаем одной ногой шаг вперед, стопы наружу. Увеличением наклона вперед создаем преднатяг (натягивается одна из ног). За счет развесовки (перемещения веса с ноги на ногу), добиваемся равномерного натяжения в ногах. Развиваем усилие до движения стоп друг от друга по направлению вперед-назад. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
