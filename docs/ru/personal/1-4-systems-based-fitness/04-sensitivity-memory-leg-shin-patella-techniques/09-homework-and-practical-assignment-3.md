# Домашнее задание

1. До следующего занятия каждый день по пол часа прорабатываем выявленные слепые зоны в ногах. Записываем результаты.
2. При необходимости, для использования гифок по памяти – устанавливаем напоминания.
3. Разучиваем гифки для приемов, которые помогают увеличить амплитуды (бывшие именно вашими ограничениями в амплитуде).
4. Два раза перечитать таблицу с костными этажами, ткнуть пальцем любую часть тела и назвать костный этаж.
5. Приучаем себя использовать фразу «тканевый объем», в привязке к костным этажам (тканевый объем от втягивания языка включает далеко не только язык, а если в речи используется слово «язык», то следить будем только за ним, упуская включающуюся шею, часть спины и т.д. только по причине не точной формулировки)
