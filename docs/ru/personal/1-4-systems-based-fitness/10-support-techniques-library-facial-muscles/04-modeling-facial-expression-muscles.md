# Моделирование: Мимические мышцы

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Из положения поворот создаем преднатяжение. Рукой взять себя за волосы, создать натяжение для оттягивания волосистой части головы вперед. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
| 2 | Из положения поворот создаем преднатяжение. Рукой взять себя за волосы, создать натяжение для оттягивания волосистой части головы назад. Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |

Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза с протоколом на уменьшение усилия |  |  |  |
