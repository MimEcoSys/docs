# Моделирование: Этажи глотки, часть 2

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Поворот головы. Поворачиваем голову до положения преднатяжения вправо, развиваем усилие до выталкивания языка наружу (вариант – упереться языком в верхние зубы), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 2 | Поворот головы. Поворачиваем голову до положения преднатяжения влево, развиваем усилие до выталкивания языка наружу (вариант – упереться языком в верхние зубы), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 3 | Поворот головы. Поворачиваем голову до положения преднатяжения влево, развиваем усилие до упора языком в уздечку языка (прижимаем язык к нижним зубам изнутри, скользим языком вниз и упираемся в уздечку), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 4 | Поворот головы. Поворачиваем голову до положения преднатяжения вправо, развиваем усилие до упора языком в уздечку языка (прижимаем язык к нижним зубам изнутри, скользим языком вниз и упираемся в уздечку), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 5 | Наклон головы. Наклоняем голову до положения преднатяжения вправо, развиваем усилие до упора языком в гладкое небо (прижимаем язык к верхним зубам изнутри, скользим языком вверх, скользим по гладкому небу, положение языка в направлении макушки), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 6 | Наклон головы. Наклоняем голову до положения преднатяжения влево, развиваем усилие до упора языком в гладкое небо (прижимаем язык к верхним зубам изнутри, скользим языком вверх, скользим по гладкому небу, положение языка в направлении макушки), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 7 | Поворот головы. Поворачиваем голову до положения преднатяжения вправо, развиваем усилие до хрюкания (попробуйте похрюкать как в детстве, обращая внимание на мышечный компонет – как напрягается небо, для того чтобы хрюкание произошло), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек. Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |

Повторяем три раза, с каждым разом, уменьшая поисковое усилие |  |  |  |
| 9 | Поворот головы. Поворачиваем голову до положения преднатяжения влево, развиваем усилие до храпа (попробуйте похрапеть, обращая внимание на мышечный компонет – как напрягаются верхние носовые ходы, ощущение стягивания и видрации), обращаем внимание, какие дополнительные тканевые объемы включились в работу, на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5-8 сек.
