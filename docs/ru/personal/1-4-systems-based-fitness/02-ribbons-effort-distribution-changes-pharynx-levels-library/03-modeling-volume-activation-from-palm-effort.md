# Моделирование: Включение дополнительных объемов от усилия в ладонях

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Где самая дальняя граница от ладоней, которая у вас напрягается |
| --- | --- | --- |
| 1 | Складываем ладошки перед собой, пальцами вверх и надавливаем ими друг на друга так, чтобы напряглись тканевые объемы до локтя |  |
| 2 | Пробуем надавить больше, так чтобы напряглось до лопаток |  |
| 3 | И еще больше пробуем надавить, так чтобы наблюдать напряжение в корпусе в сторону таза |  |
| 4 | Еще развиваем усилие, чтобы включались объемы таза и ниже, в ногах |  |
| 5 | Давим в ладони, со всей мощи |  |
| 6 | Попробуем снова понажимать в ладони три-пять раз, с незначительным усилием, и слушаем уже внимательнее, как далеко уходит напряжение с меньшим усилием нажатия, но на один заход более тренированным вниманием |  |
| 7 | Какие объемы в ногах работают при увеличении нагрузки на руки |  |
