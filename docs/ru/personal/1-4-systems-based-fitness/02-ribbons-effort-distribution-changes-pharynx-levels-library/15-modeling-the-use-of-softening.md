# Моделирование: Использование обмяканий

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Прогиб. Становимся спиной к стене, тянем таз влево, при этом отклоняясь верхней частью корпуса вправо до положения преднатяжения. Воспроизводим по памяти гифку для снятия напряжения тканевого объема, который создает сопротивление прогибу. Повторяем до момента, когда нечего вспомнить |  |  |  |
| 2 | Прогиб. Становимся спиной к стене, тянем таз вправо, при этом отклоняясь верхней частью корпуса влево до положения преднатяжения. Воспроизводим по памяти гифку для снятия напряжения тканевого объема, который создает сопротивление прогибу. Повторяем до момента, когда нечего вспомнить |  |  |  |
| 3 | Упражнение со звездочкой. Пробежаться по учебнику дальше, найти прием к костному этажу, для которого нечего вспомнить, изготовить новую гифку, и применить с замером увеличения амплитуды прогиба |  |  |  |
