# Домашнее задание

1. До следующего занятия пользуемся обмяканиями этажей глотки в бытовой и культурной жизни: при сидении за компом, поднимании сумок, открытии дверей, натягивании и стягивании штанов, выведении любимой собачки на прогулку, подметании, мытье тарелок, держании кружки. Тренируемся воспроизводить тканевые чувства по памяти, тренируемся делать те же действия с меньшим количеством усилий (достаточным усилием). Используя обмякания в привычной жизни, можно переоценивать усилия с привычных (включая паразитные) на достаточные. Запишите результаты.
2. При необходимости, для использования гифок по памяти – устанавливаем напоминания.
3. Разучиваем гифки для приемов, которые помогают увеличить амплитуды (бывшие именно вашими ограничениями в амплитуде).
4. Два раза перечитать таблицу с костными этажами, ткнуть пальцем любую часть тела и назвать костный этаж.
