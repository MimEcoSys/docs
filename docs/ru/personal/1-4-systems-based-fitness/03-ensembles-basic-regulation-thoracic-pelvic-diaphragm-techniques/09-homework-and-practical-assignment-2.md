# Домашнее задание

1. До следующего занятия проработайте грудную клетку по периметру.
2. При необходимости, для использования гифок по памяти – устанавливаем напоминания.
3. Разучиваем гифки для приемов, которые помогают увеличить амплитуды (бывшие именно вашими ограничениями в амплитуде).
4. Используем гифки в культурных движениях
5. Два раза перечитать таблицу с костными этажами, ткнуть пальцем любую часть тела и назвать костный этаж.
