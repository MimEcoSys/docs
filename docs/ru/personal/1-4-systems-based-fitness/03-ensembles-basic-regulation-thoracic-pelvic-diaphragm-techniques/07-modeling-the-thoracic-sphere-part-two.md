# Моделирование: Грудная сфера, часть 2

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
| 1 | Поворот до положения преднатяжения. Делаем выдох и довыдох, сколько получится. Развиваем усилие до стягивания передней части ребер к центру (назовем прием - ребра к груди). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 2 | Поворот до положения преднатяжения. Делаем выдох и довыдох, сколько получится. Развиваем усилие до стягивания задней части ребер к центру (назовем прием - ребра к позвоночнику). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 3 | Повторяем для каждого из 4 прогибов (вперед-назад, вправо, влево) |  |  |  |
| 4 | Прогиб влево до положения преднатяжения. Развиваем усилие до стягивания ребер друг к другу справа (для тренировки можно использовать выдох для стягивания ребер). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 5 | Прогиб вправо до положения преднатяжения. Развиваем усилие до стягивания ребер друг к другу слева (для тренировки можно использовать выдох для стягивания ребер). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 6 | Прогиб влево до положения преднатяжения. Развиваем усилие до растягивания ребер друг от друга слева (для тренировки можно использовать вдох для растягивания ребер). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
| 7 | Прогиб вправо до положения преднатяжения. Развиваем усилие до растягивания ребер друг от друга справа (для тренировки можно использовать вдох для растягивания ребер). Держим на счет 5-4-3-2-1, отпускаем, ждем дорасслабления 5–8 сек, проверяем увеличение амплитуды. Повторяем 2–3 раза до дорасслабления с протоколом на уменьшение усилия, запоминаем процесс дорасслабления, для каждой стороны, пробуем по памяти сделать дорасслабление |  |  |  |
