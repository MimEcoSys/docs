# Моделирование: Перекаты, часть 2

Выполните перечисленные приемы и запишите результаты. В независимости от движения если встретили боль, то отступаем по амплитуде и интенсивности усилия.

|  | Приемы | Описание ощущения | Описание регуляции | Описание действия |
| --- | --- | --- | --- | --- |
|  | 1 | Из положения стоя опускаемся на корточки (оторвав пятки от пола), и тренируем падение – через проворот корпуса на одной ноге укладываем на пол колено (сформировав новое пятно опоры), и укладываем второе колено. Повторить три раза |  |  |  |
|  | 2 | Из финального положения предыдущего приема перенести ступню на ногу (крест-накрест чтобы ступни оказались) перенести вес и продолжить перекатывание до положения сидя на тазовых костях |  |  |  |
|  | 3 | Из финального положения предыдущего приема сидя на полу, опускаем корпус к колену поднятой рукой образуя прямую линию рука-колено и перенося вес перекатываемся на спину |  |  |  |
