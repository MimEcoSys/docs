# R1.5:Tasks3 - «Одна задача – один рабочий продукт – в один подход»

Выполнение этого задания (предпоследнего в текущей резидентуре) начните через 3-4 дня после того, как вы начнёте *планирование по работоспособности*, выполняя R1.5:Tasks2.

Предварительно определите максимальную достижимую для вас продолжительность “*одного подхода*” Это то время, с течение которого вы можете сохранять фокус на решаемой задаче и бороться с отвлечениями. Настраивайте размер *помидорки* так, чтобы она была равна “одному подходу”. Вы должны чередовать *“подходы”* с перерывами на отдых, с соответствии с практикой *“Помодоро”*.

1. Дополните описания задач в вашем плане описаниями результатов как “рабочих продуктов”. Напомним, рабочий продукт - это то, что вы можете показать кому-то другому, хотя бы для промежуточной оценки или получения консультации, и он будет понятен. Если создание одного рабочего продукта требует выполнения нескольких задач из планировщика - сгруппируйте их вместе.
2. Измените план так, чтобы задачи, направленные на создание одного рабочего продукта - шли одна за другой, не разбиваясь другими задачами. По сути - укрупните эти задачи в одну, с оценкой полного времени и единым приоритетом. Если полное рабочее время превышает “один подход” - разбейте задачу вновь, но с соблюдением важного принципа: теперь для каждой задачи надо определить рабочий продукт, полученный в результате её выполнения (или указать то состояние рабочего продукта, в который он приходит в результате выполнения этой задачи).
3. Начните планировать выполнение укрупнённых задач (имеющих один итоговый рабочий продукт каждая) так, чтобы они полностью укладывались в “подходы” в вашем планировщике до их полного выполнения. Желательно также ставить подряд “подходы” к логически связанным задачам, выполнять их без переключения между проектами. Обеспечьте для начала работу без переключений (до полного выполнения) в периоды максимальной работоспособности и для задач из приоритетных проектов. Когда вы освоите эту практику, вы получите опыт и резерв времени для постепенного перехода к ней для всех задач.
4. Через 3-4 дня планирования по этому методу опишите результат и ваши ощущения. Выросла ли ваша собранность, проявилось ли это в скорости работы?. Опубликуйте пост в Aisystant (для проходящих резидентуру с наставниками) либо в клубе МИМ.
