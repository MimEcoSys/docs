# R1.3:Tasks1 - Задание: Выявляем скрытые работы

Попробуйте определить реальное количество работ, выполняемых «мимо плана», и начать вырабатывать привычку планировать их выполнение явно.

Следуйте правилу *“отражаю в экзокортексе всё, что делаю”*. Выделите в экзокортексе место для фиксации плана работ.

Это может быть просто расширение таблицы из задания R1.2:Tasks1, вносите планы в ту же таблицу, только дополните её столбцами для отражения:

→ **Планового начала и окончания работы**.

→ **Приоритета**.

→ **Проекта** - для связи работы с проектом, в рамках которого она ведётся (такая связь обычно есть для плановых работ, для прочих типов работ - есть не всегда).

→ **Тип работы**: *плановая, непредвиденная, стихийная, скрытая*.

Вы можете завести для учёта планируемых работ отдельную табличку, или работать с уже используемой вами системой таск-менеджмента из личного или корпоративного экзокортекса.

Теперь ведущийся вами хронометраж должен быть обязательно связан с планом - работа в табличке хронометража обязательно должна быть внесена и в план, пусть пост-фактум. Это правило надо обязательно выполнять для *продуктивной активности*, желательно и для *инвестиционной*. Для *лишней активности* в рамках работы - это тоже обязательная связь. Для *бытовых активностей, отдыха и ТО* - этой связи не требуется.

1. Убедитесь, что у вас есть список рабочих проектов, желательно - с приоритетами.
2. Сформируйте очередь задач на выполнение, начав с запланированных задач по рабочим проектам, в соответствии с той системой приоритетов, которая у вас есть. Обязательно заносите приоритеты в таблицу.
3. Скрытые, стихийные и непредвиденные задачи тоже добавляете в очередь по мере их обнаружения. Нет задачи в очереди – она не выполняется и не включается в хронометраж (для рабочих задач).
4. В конце дня / начале следующего подводите итог: сколько задач вы внесли в очередь, сколько начали, сколько выполнили. Сколько оказались скрытыми, то есть были внесены в план уже после того, как вы начали их выполнять?
5. В конце дня / начале следующего подводите итог по таблице хронометража: Сколько времени выполнялись скрытые задачи в среднем? Сколько часов от вашей продуктивной (или продуктивной + инвестиционной) мощности они занимают? Какой процент времени от продуктивного или продуктивного + инвестиционного времени они занимают? Сколько времени остаётся на плановые задачи (плановая нагрузка)? Попробуйте публиковать эту статистику каждый день.
6. По окончании первой недели опишите результат. Опубликуйте пост в Aisystant (для проходящих резидентуру с наставниками) либо в клубе МИМ. После того как вы выполните задание сами, его можно дать вашим сотрудникам.
