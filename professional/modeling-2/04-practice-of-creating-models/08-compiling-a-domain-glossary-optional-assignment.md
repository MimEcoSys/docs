# R3.4:Tasks2 - Составляем глоссарий предметной области (факультативное задание)

Составьте глоссарий/словарь базовых понятий для той предметной области, в которой вы собираетесь составлять описание/моделировать.

Изучите статьи «Личная база знаний» [https://tenchat.ru/media/1099826-lichnaya-baza-znaniy-chto-eto-takoye-i-zachem-ona-nuzhna](https://tenchat.ru/media/1099826-lichnaya-baza-znaniy-chto-eto-takoye-i-zachem-ona-nuzhna) и «Понятийная база» [https://tenchat.ru/media/1103885-lichnaya-baza-znaniy-ponyatiynaya-baza-conceptbase](https://tenchat.ru/media/1103885-lichnaya-baza-znaniy-ponyatiynaya-baza-conceptbase)

Выберите систему экзокортекса, которую вы будете использовать для составления глоссария. Это должен быть удобный для вас экзокортекс, поддерживающий перекрестные ссылки. Если нужны подсказки по выбору экзокортекса, то обратитесь к статьям «Какой экзокортекс выбрать для личной базы знаний» часть 1 [https://tenchat.ru/media/1126790-kakoy-ekzokorteks-vybrat-dlya-lichnoy-bazy-znaniy](https://tenchat.ru/media/1126790-kakoy-ekzokorteks-vybrat-dlya-lichnoy-bazy-znaniy) и часть 2 [https://tenchat.ru/media/1128353-kakoy-ekzokorteks-vybrat-dlya-lichnoy-bazy-znaniy-chast-2-primery](https://tenchat.ru/media/1128353-kakoy-ekzokorteks-vybrat-dlya-lichnoy-bazy-znaniy-chast-2-primery)

Это факультативное задание, вы можете отложить его выполнение до окончания резидентуры, но мы рекомендуем вам рано или поздно найти для него время! Практика ведения понятийной базы заменяет практику конспектирования при обучении, и заставляет четче определять объекты внимания практически в любой деятельности. Вы можете применить эти методы для создания личной понятийной базы, чтобы осваивать новый материал из руководств МИМ, или на работе

1. Кратко опишите выбранную систему экзокортекса и технологию ведения глоссария в ней.
2. Составьте глоссарий/понятийную базу/словарь для выбранной предметной области в выбранном экзокортексе. Опишите хотя бы 5-10 ключевых понятий, которые нужны для вашего описания. Выложите результат в своём блоге и дайте ссылку.
