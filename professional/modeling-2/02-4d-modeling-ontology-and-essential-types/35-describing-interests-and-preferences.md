# R3.2:Mod7 - Описываем интересы и предпочтения

Начните с трех самых важных для вас ролей (рабочих или личных). Выберите для каждой роли минимум один метод/практику, и основной объект этой роли/практики. Если вы захотите описать у одной роли несколько методов или в одном методе несколько важных объектов - заведите на каждый объект в каждом методе по новой строке. Укажите для объектов их класс/тип в соответствии с нашей онтологией, используя значок ::

В последней колонке опишите предпочтения для данного объекта в виде пар «характеристика: значение».

А теперь попробуйте добавить в эту таблицу другую роль, обычно исполняемую кем-то другим, у которой будет иное (даже противоположное) предпочтение по той же характеристике того же объекта интереса.

| Роль | Метод/практика | Объект интереса | Предпочтение (характеристика: значение) |
