# Вопросы. Системы создания

Программист Петя не может работать без ВКонтакте. Если он не напишет трех постов за день, у него наступает синдром абстиненции. ВКонтакте является:

1. Целевой системой программиста Пети
2. Системой создания Пети как программиста
3. Системой в окружении Пети
4. Надсистемой программиста Пети

Программист Петя работает над новой компьютерной игрой. Каждую неделю он пишет отчёт о ходе своих работ и подаёт заполненную ведомость затраченного им времени (таймшит) руководителю проекта Васе.

1. Отчёт документирует целевую систему, таймшит документирует систему создания
2. Отчёт документирует систему создания, таймшит документирует целевую систему
3. Отчёт и таймшит документируют систему создания
4. Ни один из этих ответов не верен

Руководитель проекта Вася работает над компьютерной игрой. Каждую неделю он пишет отчёт о ходе работ команды и посылает заполненную ведомость затраченного командой времени (таймшит) заказчику Гене.

1. Отчёт документирует целевую систему, таймшит документирует систему создания
2. Отчёт документирует систему создания, таймшит документирует целевую систему
3. Отчёт и таймшит документируют систему создания
4. Ни один из этих ответов не верен

1. Создателем

1. Надсистемой
