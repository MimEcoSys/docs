# Моделирование: заземление абстрактных текстов

Напишите граундинг-эквиваленты/заземления для приведённых текстов, не меньше двух разных. Пример приведён в первой строчке таблицы.

| Номер п/п | Абстрактный текст | Заземление |
| --- | --- | --- |
| Пример | Воплощение системы должно соответствовать стандартам. | Компьютер должен обеспечивать подключение внешних устройств по стандарту USB 3.2. Мороженое «Пломбир» должно соответствовать ГОСТ 31457-2012 |
| 1. | Документация должна быть компактной. |  |
| 2. | Наше устройство прочное. |  |
| 3. | Объект внимания, который даётся в методе системного мышления. |  |
| 4. | Пришло сообщение. |  |
