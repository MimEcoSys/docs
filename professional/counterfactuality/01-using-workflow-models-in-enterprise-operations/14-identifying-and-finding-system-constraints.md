# R4.1:Tasks3 - Ищем ограничение

Вернитесь к своим рассуждениям по заданию «R4.1:Tasks2 - Ищем физику своего предприятия». Найдите в описании своей производственной линии ограничение (или сформируйте наилучшую гипотезу о том, где может быть это ограничение). Ответьте на ряд вопросов ниже:

1. Какая рабочая станция в вашей производственной линии может с наибольшей вероятностью являться ограничением? Какие признаки заставляют вас сформировать эту гипотезу?
2. Какие измерения вы могли бы предпринять для подтверждения (или опровержения) этой гипотезы? Приведите пример возможных результатов таких измерений (вообразите себе набор исторических данных, исходя из длины производственного цикла и ваших представлений об обычных сроках работ, их изменчивости, вероятности возникновения задержек и проблем). Проведите для этих воображаемых данных оценку нескольких ключевых параметров работы производственной линии, подтверждающих наличие ограничений. После этого хорошо бы запланировать реальные изменения!
3. Укажите, где в вашей производственной линии возможно создание буферов? Или, может быть, эти буфера уже существуют (помните, что они могут существовать по факту, хотя методология их использования не формализована!)? Каких типов могли бы быть (или есть уже) эти буфера? Приведите хотя бы один пример.
