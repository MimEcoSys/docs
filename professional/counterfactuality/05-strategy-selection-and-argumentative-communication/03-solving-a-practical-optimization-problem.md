# R4.5:Tasks1 - Решаем задачу оптимизации

Попробуйте описать вырабатываемое вами решение проблемы как задачу многокритериальной оптимизации.

1. Назовите решаемую проблему.
2. Перечислите параметры, влияющие на выбор решения, укажите, следует ли добиваться максимизации или минимизации каждого параметра.
3. Перечислите пары конфликтующих параметров, и/или пары параметров, связанных отношением убывающей отдачи.
4. Охарактеризуйте хотя бы два Парето-оптимальных решения, то есть таких решения, в которых невозможно улучшить один параметр без ухудшения других.
