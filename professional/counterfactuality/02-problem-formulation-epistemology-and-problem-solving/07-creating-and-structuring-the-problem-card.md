# R4.2:Tasks1 - Формируем карточку проблемы

1. Создайте собственный шаблон карточки проблемы для предварительного описания часто встречающихся у вас проблем. Озаглавьте разделы шаблона, сформируйте рекомендации по их заполнению. Используйте материалы предыдущего подраздела, но сделайте специализированный шаблон для (относительно) узкого класса проблем какой-то знакомой вам предметной области (продажи, разработка, тестирование, производство, учёт и т.п.). Постарайтесь использовать специальную терминологию выбранной предметной области, чтобы шаблон был понятен специалистам, для которых он предназначен.
2. Приведите примеры описания 2-3 рабочих проблем по созданному шаблону.
3. Проверьте, насколько хороший получился шаблон — отдайте описанную проблему коллеге и попросите его прокомментировать понятность описания. Приведите оценки коллеги.
