# R4.2:Tasks2 - Планируем вмешательство

Предложите шаблон описания вмешательства. Шаблон должен содержать предполагаемую последовательность изменений: что вы меняете, какой механизм затрагиваете, какое нежелательное последствие ожидаете уменьшить или остановить, к чему предлагается адаптироваться. Не забудьте про вариант с сохранением всего как есть (если найти разные вмешательства затруднительно). Если вы предлагаете сочетание мер, предусмотрите рассмотрение их совместимость.

Шаблон должен содержать проверку: за чем вы будете наблюдать, с чем сравнивать, какой результат сравнения будет свидетельствовать о решении проблемы, а какой – о необходимости пересмотра решения.

Выберите одну из подготовленных в предыдущем задании Карточек проблем и предложите 2-3 содержательно разных вмешательства. Опишите их по шаблону.

1. Предложите шаблон описания вмешательства. Озаглавьте разделы шаблона, сформируйте рекомендации по их заполнению. Постарайтесь использовать специальную терминологию выбранной предметной области, чтобы шаблон был понятен специалистам, для которых он предназначен.
2. Скопируйте для одной из проблем её формулировку в общем виде из задания «R4.2:Tasks1 - Формируем карточку проблемы».
3. Опишите по шаблону первое возможное вмешательство.
4. Опишите по шаблону второе возможное вмешательство.
5. Опишите по шаблону третье возможное вмешательство (если есть).
