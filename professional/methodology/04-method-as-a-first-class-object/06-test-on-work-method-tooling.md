# TEST Инструментарий

Выберите части, которые могут входить в инструментарий тренировок прыжков в высоту:

1. Учебник «Как научиться прыгать»
2. Учебник физики для физкультурных вузов
3. Планка и стойки для её крепления
4. Мягкий мат
5. Секундомер
6. Рулетка
7. Покрытие дорожки для разбега
8. Зрители соревнований по лёгкой атлетике
9. Видеокамера для замедленной съёмки
10. Соревнования по прыжкам в высоту

В инструментарий инженерных расчётов могут входить:

1. Учебник математического анализа
2. Задачник по математическому анализу
3. Логарифмическая линейка
4. Калькулятор
5. Научный калькулятор (с корнями, тригонометрией, логарифмами и т.п.)
6. Математические программы (Mathematica, Maple, Sagemath, Oscar или аналогичные)
7. Специализированные программы инженерных расчётов
8. Проектное бюро, в котором используются все прочие предметы из перечисленных тут
9. Инженер Пётр, который может воспользоваться всеми возможностями проектного бюро

Инструментарий машинописи может включать в себя:

1. Слепой десятипальцевый метод
2. Повязку на глаза
3. Десять пальцев
4. Компьютерную клавиатуру
5. Механическую пишущую машинку

Культура приёма экзаменов может задействовать следующий инструментарий:

1. Наборы вопросов на листочках (билеты)
2. Учебник по предмету экзамена
3. Учебник «Как вести себя на экзамене»
4. Методическое пособие «Что нужно знать экзаменатору»
5. Помещение для приёма экзамена (отвечающее требованиям к уровню шума, освещению, входу-выходу, глушению сигнала мобильных телефонов)
6. Экзаменационная ведомость
7. Шпаргалки
8. Оборудование для записи устных ответов (диктофон, вебкамера, видеорегистратор)
9. Вскрытие конвертов с вопросами непосредственно перед экзаменом
10. Бланки для подачи апелляции на результаты экзамена
