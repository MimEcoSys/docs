# TEST Онтология метода

С какими утверждениями можно согласиться?

1. Вид труда — это метод работы исполнителей какой-то профессиональной роли.
2. Метод — это использование инструментов в оргзвеньях
3. Технологии — это практики работы. Скажем, технология получения сверхчистых полупроводников — это просто синоним для практики получения сверхчистых полупроводников.
4. Практика — это какая-то инженерная или менеджерская дисциплина. Практика операционного менеджмента, например — это дисциплина операционного менеджмента.
5. Метод можно выполнять

Выберите примеры разложения метода:

1. способы стыковки космических кораблей делятся на автоматическую стыковку и ручную стыковку
2. приготовление борща делится на подготовку овощей, подготовку мяса, варку. Подготовка овощей состоит из их очистки, нарезки, пассировки.
3. культура приготовления кофе состоит из приготовления кофе в кофемашине эспрессо, приготовления кофе в капельной кофеварке, использования френч-пресса, заваривания по-турецки. Приготовление кофе в кофемашине включает использование рожковой кофе-машины и капсульной кофе-машины.
4. плавание включает в себя дыхание, движения руками, движение ногами
