# TEST Методы

Семён пошёл на тренинг по продажам, потому что:

1. Хочет освоить эту стадию жизненного цикла проекта
2. Хочет освоить метод работы

Идя на ежедневную тренировку, Петя сегодня увидел разбитую тротуарную плитку, и перепрыгнул через дырку. Для Пети это:

1. Действие
2. Метод
3. Работа
4. Стадия пути на тренировку

По дороге на тренировку Петя обычно не наступает на границы между тротуарными плитками, он их обязательно перешагивает. Для Пети это:

1. Действие
2. Практика
3. Работа
4. Стадия пути на тренировку

Саша поцеловал Дашу от избытка чувств. Для Саши это:

1. Действие
2. Стиль
3. Работа
4. Стадия встречи

Саша обычно целуется со знакомыми при встрече, на это уходит по двадцать секунд на каждого встреченного. Для Саши это:

1. Действие
2. Стиль
3. Стадия встречи

Дмитрий поскользнулся и упал. Он подумал, что должен существовать метод безопасных падений, который убережёт его от ушибов, и пошёл искать курсы по этому методу. Он:

1. Быстро найдёт подходящие курсы
2. Это он просто упал, таких методов нет и курсов не будет

Геодезист 1-й категории Игорь установил теодолит по уровню. Он:

1. Выполнял практику установки теодолита
2. Просто установил теодолит, никаких методов
3. Ответ «выполнял метод» или «просто установил, никаких методов» зависит от того, как его учили
4. Ответ «выполнял культуру установки» или «просто установил» зависит от того, кто отвечает на этот вопрос

Метод прыжков в высоту «ножницами» по отношению к методу прыжков в высоту является:

1. Одним из вариантов метода
2. Функциональной частью
3. Независимым объектом, не связанным никакими отношениями

Культура системного мышления:

1. Является одним из видов мышления как метода работы
2. Является функциональной частью практики мышления
3. Не является практикой
